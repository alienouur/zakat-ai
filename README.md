# zakat-ai — مستشار فقه الزكاة متعدد المناهج

تطبيق ويب (FastAPI + واجهة RTL) يجيب عن مسائل الزكاة اعتمادًا على قاعدة معرفة موثقة ومستقلة لكل منهج:

| Clone | المصدر |
|---|---|
| `albani` | محاكاة منهج الشيخ الألباني (جامع تراث الألباني في الفقه، إرواء الغليل، تسجيلات al-albany.com) |
| `ibn_uthaymeen` | محاكاة منهج الشيخ ابن عثيمين (binothaimeen.net، مجموع الفتاوى، الشرح الممتع) |
| `ibn_baz` | محاكاة منهج الشيخ ابن باز (binbaz.org.sa، مجموع الفتاوى) |
| `maliki` | المنهج الفقهي المالكي (الرسالة، مختصر خليل، الشرح الكبير وحاشية الدسوقي…) مع تمييز المشهور عن الأقوال الأخرى |
| `comparative` | مقارن يعرض أقوال المناهج الأربعة ونقاط الاتفاق والاختلاف دون ترجيح من عنده |

لا يدّعي أي Clone أنه العالم نفسه، وكل حكم يُعرض مع مصدره وحالة التحقق منه.

## التشغيل

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
uvicorn app.main:app --reload
```

ثم افتح `http://127.0.0.1:8000/`.

### طبقة Gemini الاختيارية

```bash
export GEMINI_API_KEY=...            # بدونه يعمل النظام بالقوالب فقط
export GEMINI_MODEL=gemini-2.5-flash  # اختياري
```

النموذج لا يختار السجلات ولا يقرر الحكم ولا يحسب؛ يستلم الجواب المركّب من السجلات ويعيد صياغته فقط (`app/llm.py`). يُرفض ناتجه ويُعرض القالب كما هو إذا احتوى رقمًا أو رابطًا غير موجود في المادة، أو لغة تفضيل («الأصح»، «الراجح») غير منقولة عن عالم، أو تكلّم بلسان الشيخ، أو تعذّر الاتصال. يمكن تعطيله لطلب واحد بـ `"use_llm": false`.

## التحقق

```bash
pytest                         # اختبارات الاستخراج والاسترجاع والحاسبة والـ API
ruff check app scripts tests   # lint
python scripts/verify_sources.py [clone]   # يجلب كل روابط المصادر ويتحقق من وجود الاقتباس فيها
python scripts/smoke_api.py    # يطبع إجابات نموذجية من كل Clone
```

## تدفق الإجابة

```
سؤال المستخدم → تصنيف الموضوع → استخراج البيانات الصريحة → أسئلة توضيحية (≤3 في الدورة، لا افتراض)
→ استرجاع BM25 من dataset الـ Clone وحده → فلترة التحقق (لا تُستعمل سجلات unverified للحكم)
→ تركيب الإجابة بطبقات: الحكم / الدليل / قول العالم / التطبيق / الحساب / الخلاصة / التوثيق
→ (اختياري) إعادة صياغة Gemini مقيّدة بالمادة نفسها، مع تحقق آلي يرفض أي إضافة
```

الحساب الرياضي منفصل عن الحكم، ويحتاج أسعار الذهب/الفضة والصرف مع `source` و`as_of`؛ إن تعذر جلبها مباشرة يُطلب سعر يدوي ولا يُستعمل سعر قديم بصمت.

## بنية قاعدة المعرفة

`zakat_knowledge_base/<clone>/{books,fatwas,hadith,classical_books,...}/*.json` — كل ملف قائمة سجلات بالمخطط المعرّف في `app/kb.py` (`Record`/`Source`)، و`metadata/clone.json` يحمل هوية الـ Clone ومعاملات الحساب المسندة إلى سجلات (`basis_records`).
